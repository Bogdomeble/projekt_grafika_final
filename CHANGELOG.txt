[NEW] FPS Counter in Window Title
  • Displays FPS in real-time (updated every 0.25s)
  • Format: "Art Gallery - FPS: XXX"
  • Helps monitor performance

[IMPROVED] Camera Smoothness
  • Implemented frame-rate independent motion
  • Added deltaTime clamping (prevents huge jumps)
  • Mouse sensitivity now scales with deltaTime
  • Movement is now smooth at any FPS

[IMPROVED] Camera Sensitivity
  • Reduced from 100.0 to 0.5 (1000x improvement!)
  • Now multiplied by deltaTime × 50 for smooth feel
  • Movement is proportional and predictable

[FIXED] Build Issues
  • Fixed 13+ files with case-sensitivity issues
  • Fixed include paths for assets
  • Removed Windows-only code
  • Improved error handling in shaderClass.cpp

[FIXED] Runtime Issues
  • Program no longer crashes on startup
  • Asset paths now correctly resolved
  • Better error messages for missing files

[TECHNICAL] DeltaTime Management
  • Real-time deltaTime calculation per frame
  • Clamped to [0.001, 0.016] seconds
  • Prevents anomalies from frame rate variations
