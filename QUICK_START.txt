QUICK BUILD (All Platforms)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALL DEPENDENCIES:

   Linux (Ubuntu/Debian):
   $ sudo apt-get update
   $ sudo apt-get install cmake libglfw3-dev libglm-dev libgl1-mesa-dev

   macOS:
   $ brew install cmake glfw glm

   Windows (with vcpkg):
   > vcpkg install glfw3:x64-windows glm:x64-windows

2. BUILD:

   $ cd projekt_grafika_final
   $ mkdir build && cd build
   $ cmake -DCMAKE_BUILD_TYPE=Release ..
   $ cmake --build . -j$(nproc)

   Or use the build script:
   $ chmod +x ../build.sh
   $ ../build.sh --release

3. RUN:

   Linux/macOS:
   $ ./bin/ArtGallery

   Windows:
   > .\bin\ArtGallery.exe

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: CMake not found
Solution: Install CMake 3.15+ from https://cmake.org/download/

Problem: GLFW not found
Solution: Ubuntu: sudo apt-get install libglfw3-dev
         macOS: brew install glfw

Problem: Shader/Texture loading fails
Solution: Ensure build/bin/shaders/ and build/bin/textures/ exist
         (Should be created automatically by CMake)

Problem: Low FPS
Solution: Use Release build instead of Debug
         Change viewport resolution in src/main.cpp

Problem: Permission denied on Linux
Solution: chmod +x build/bin/ArtGallery
         ./build/bin/ArtGallery

For more detailed troubleshooting, see BUILD_GUIDE.md
