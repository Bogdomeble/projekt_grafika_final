     → Naprawiłem: Ścieżki do assetów

  ✅ Problem: Program crashował (aborted core dumped)
     → Naprawiłem: Obsługę błędów w shaderClass.cpp
     → Naprawiłem: Ścieżki do shaderów i tekstur
     → Dodałem: Lepsze komunikaty błędów

  ✅ Problem: Kamera obłędnie czuła
     → Zmieniam: sensitivity z 100.0 na 0.1
     → Naprawiłem: Speed calculation (nie mnożyć 2x deltaTime)
     → Dodałem: Rzeczywisty deltaTime tracking

  1. Upewnij się że jesteś w build/bin/:
     $ pwd  # powinna być .../build/bin

  2. Upewnij się że assets istnieją:
     $ ls assets/shaders/
     $ ls assets/textures/

  3. Sprawdź czy biblioteki zainstalowano:
     $ sudo apt-get install libgl1-mesa-dev libxrandr-dev

  4. Przebuduj:
     $ cd build && cmake --build . -j4
